Bid2Have API Tester

Guía interactiva para probar cada endpoint del contrato contra tu backend local. Abrí este archivo directo en el navegador (doble clic) — no depende del dev server de Vite. Los endpoints marcados auth necesitan el token pegado abajo; admin además requiere un usuario con rol SUPERADMIN.

Antes de usarlo: el backend (../Bid2Have/src/index.ts) no tiene middleware de CORS en las rutas REST — solo Socket.IO permite cualquier origen. Si ves "Failed to fetch" o requests que nunca llegan, es eso (no un bug de esta página): el navegador bloquea el preflight OPTIONS porque no hay Access-Control-Allow-Origin en la respuesta. Para que esto (y el propio frontend React en otro puerto) funcione, hay que agregar cors() en src/index.ts del backend.
